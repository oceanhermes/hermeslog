# Income Flow

Create a clean and modern income tracking dashboard.

The dashboard is used to record and monitor incoming money over time.

Main requirements:

Display a summary card for Total Income.

Display a transaction history containing:

Date

Income Amount

Provide an Add Income button.

When adding income, the user can input:

Date

Amount

Show income records from newest to oldest.

Add a simple date filter so users can view income by specific date or date range.

Use Indonesian Rupiah (IDR) formatting, for example: Rp1.500.000.

Include a simple income chart showing income trends over time.

Design:

Clean, minimal, and modern dashboard.

Simple card-based layout.

Good spacing and clear typography.

Responsive for desktop and mobile.

Avoid unnecessary elements or overly complex analytics.

Focus on making the income amount and transaction dates easy to read.

Example transaction data:

6 October 2026 — Rp500.000

5 October 2026 — Rp250.000

3 October 2026 — Rp1.000.000
